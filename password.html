      How the scoring works

      Each password gets a raw entropy score in bits: length × log₂(alphabet). The alphabet is the sum of character-class sizes the password actually uses (lowercase = 26, digits = 10, ASCII symbols = 33, etc.). That raw score is then penalized for patterns a real cracker tries first: dictionary hits, sequential runs like abcd, repeats like aaaa, keyboard walks like qwerty, and four-digit years.

      Crack time = 2bits / 2 guesses, divided by the attacker's speed. Real cracking uses smarter strategies than brute force, so think of these numbers as a best case for you and a worst case for the attacker.

      The Python implementation that backs this lives at password.py in this repo; the JS port that runs on this page is a line-for-line mirror.
